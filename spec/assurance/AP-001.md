# tl-parse v0.1 text-boundary assurance profile

## Decision Boundary

Evidence supports a human decision about one exact source, dialect,
dependency, corpus, and toolchain candidate. It does not prove temporal
semantics, qualify a consuming application, or authorize registry publication.

## Impact Scenarios

Material scenarios are silent source reinterpretation and hostile-input
resource growth. Exact grammar tests, pinned graph validation, round trips,
negative corpora, fuzz seeds, and budget-boundary tests detect these before
release for the exercised population.

## Evidence Policy

Evidence identifies input class, dialect/dependency/corpus revisions, limits,
diagnostic schema, checks, outcomes, and limitations. Invalid, exhausted, or
tool-error states are not successful parses. Only `@kreneskyp` may approve the
source release.

## Exceptions

No exception is implicit. Any exception names its owner, affected criterion,
rationale, expiry, evidence impact, and explicit human acceptance.
