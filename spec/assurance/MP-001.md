# tl-parse v0.1 Measurement Plan

## Decision Use

The evidence informs the human source-release decision. Passing measurements
do not themselves approve, certify, accredit, publish, or qualify a consumer.

## Population

The population is every TM-001 criterion, operator class, malformed/resource
fixture, fuzz seed, generated case, CLI path, public check, and schema gate in
the exact candidate revision.

## Measures

| Measure | Population | Required outcome |
|---|---|---|
| Requirement coverage | Every TM-001 row and referenced Rust evidence symbol | 100% backed |
| Dialect mapping | Every constant, proposition, delimiter, and operator class | exact expected node/token result |
| Diagnostic stability | Golden malformed cases and repeated serialization | exact code/span/expected/found/recovery bytes |
| Resource behavior | Every parser and formatter logical limit | explicit bounded failure, no success artifact |
| Round trip | Deterministic generated formula population and fuzz seeds | no structural/profile drift |
| Corpus integrity | Manifest, malformed fixtures, and seeds | all hashes verify |
| Candidate evidence | Every invoked local gate and schema validator | recorded status and immutable digest |

## Collection Procedure

The evidence collector runs from a clean exact commit, refuses to overwrite a
run, captures stdout/stderr/status separately, records tools and dependencies,
validates local schemas plus the pinned PGM-01 envelope, and writes a SHA-256
manifest. Failed runs remain retained.

## Interpretation

Passing deterministic checks supports independent review of the exact
candidate. Generated and fuzz populations do not prove all possible inputs.
Human review and release state remain pending in candidate evidence.
